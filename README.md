# Uncertainty Quantification for Agentic AI via Conformal Prediction
This repository hosts the research on incorporating conformal prediction into agentic AI frameworks. Conformal prediction provides statistically valid, model-agnostic uncertainty estimates, which are crucial for improving the robustness, safety, and interpretability of autonomous agents. The project explores how confidence sets, calibrated thresholds, and conformal scores can guide planning, action selection, and error detection in LLM-driven agents. The repo includes modular code, reproducible experiments, and benchmarking utilities.
