================================================================================
Conf-ReAct — ScienceWorld Reproduction Guide
================================================================================

"Conf-ReAct" (this folder) = conformal-guided BFS planning for ScienceWorld:
at each state the LLM samples candidate actions, a trained score model scores
them, and a conformal prediction set (dual-LP, Gibbs et al. 2023) restricts
which actions get expanded.

Key difference from WebShop / Game of 24: ScienceWorld has no live oracle at
PLAY time — the only ground truth is the static gold action sequence
env.get_gold_action_sequence() returns at episode start. So:
  * Training data is collected via GOLD-PATH TEACHER FORCING (every recorded
    state is on the gold path), not free rollout.
  * Online BFS play almost always leaves the gold path within the first step,
    so per-state coverage is measurable OFFLINE on held-out gold states, not
    from the live BFS logs the way WebShop/Game24 do it. (Section 6 below.)

No server needed — `scienceworld` is a local pip package. No hosted/commercial
API is used anywhere.

Layout
    README.txt                          this file
    react_sciworld.py                   ReAct rollout + MPO-211 test-set
                                        loader (PRESETS, load_mpo_testset,
                                        aggregate) — imported by bfs_conformal_211.py
    examples/scienceworld_react_prompt.py   few-shot prompt
    mpo_data/                           the 211-task MPO/ReflAct test split
    data_generation_sciworld.py         Stage 1: gold-path teacher-forced rollout
    add_optimal_and_bins_sciworld.py    Stage 2: raw pkl -> binned "_2_" pkl
    augment_traj_intersection_sciworld.py   Stage 2b (OPTIONAL, see note below)
    merge_aug_optimals.py               Stage 2c (OPTIONAL, see note below)
    score_model.py                      score-model architecture + BertEmbeddingCache
    train_score.py                      Stage 3: train the score model
    conformal_predictor.py              dual-LP conformal predictor
    run_conformal_calibration.py        Stage 4: calibrate
    bfs_conformal_sciworld_game24_style.py   BFS algorithm (imported by bfs_conformal_211.py)
    bfs_conformal_211.py                Stage 5: the Conf-ReAct search itself
                                        (RAM-light, shardable — the actual
                                        entry point used to produce results)
    dump_setsize_coverage_sciworld.py   Stage 6a: offline per-state coverage dump
    reflexion_selfset_sciworld.py       Stage 6b: self-sized-set baseline generator
    plot_setsize_distribution_coverage_sciworld.py   Stage 6c: the set-size figure
    table_coverage_vs_setsize_sciworld.py   Stage 6d: empirical coverage table

Not included: trained score-model checkpoints, BERT caches, and training
pickles — all regenerated by Stages 1-4. The full-precompute BERT cache was
38-78 GB per model in the source project (one CLS embedding per unique
instruction/action string; ScienceWorld's action space is far larger than
WebShop's or Game of 24's, hence the bigger cache).

NOTE on Stage 2b/2c (augment_traj_intersection_sciworld.py, merge_aug_optimals.py):
the calibration/search pipeline shipped here (Stages 3-5) uses the plain
Stage-2 output (training_data_2_sciworld.pkl) for all three models, matching
what the Qwen2.5-3B and Gemma-4-12B runs in the source project actually used.
The Qwen3-8B run additionally ran Stage 2b (off-gold-path data augmentation
via trajectory-intersection bushwhacking) and Stage 2c (merging it into the
gold data as training_data_merged_sciworld.pkl) before calibrating — a real
enhancement specific to that one model's run, included here for completeness
but not required for the core method. To reproduce it: run Stage 2b then
Stage 2c, and point run_conformal_calibration.py / bfs_conformal_sciworld_game24_style.py's
--data at training_data_merged_sciworld.pkl instead of training_data_2_sciworld.pkl.


================================================================================
1. PREREQUISITES
================================================================================

    pip install scienceworld
    vllm serve Qwen/Qwen3-8B --port 8001

Python packages: torch, transformers, openai, matplotlib, numpy


================================================================================
2. STAGE 1-2 — TRAINING DATA
================================================================================

Stage 1 (data_generation_sciworld.py) teacher-forces along the gold action
sequence and records a training example at every gold-path state:

    python data_generation_sciworld.py --task-num 13 --num-variations 20 \
        --n-samples 10 --out training_data_sciworld.pkl

Edit MODEL_NAME / the OpenAI client's base_url at the top of the file for the
model you're collecting data with (no CLI override for this stage).

Options:
    --task-num N          ScienceWorld task index                (default 13)
    --var-start N          starting variation index                (default 0)
    --num-variations N      variations to collect                   (default 20)
    --n-samples N            LLM candidate samples per state          (default 10)
    --temperature F           (default 0.7)
    --simplifications-preset   (default "paper")
    --env-step-limit N          (default 200)
    --out PATH                  (default training_data_sciworld.pkl, this folder)

Stage 2 (add_optimal_and_bins_sciworld.py) adds the 10-bin softmax histogram
feature:

    python add_optimal_and_bins_sciworld.py --in training_data_sciworld.pkl \
        --out training_data_2_sciworld.pkl

Options: --in, --out, --drop-unlabeled (drop states with no computable label).


================================================================================
3. STAGE 3 — TRAIN THE SCORE MODEL  (train_score.py)
================================================================================

    python train_score.py
    python train_score.py --data training_data_2_sciworld.pkl --epochs 150

Output, written to ./trained_models/:
    best_score_model.pt, bert_cache.pkl (see size note above), loss_curve.png


================================================================================
4. STAGE 4 — CALIBRATE  (run_conformal_calibration.py)
================================================================================

    python run_conformal_calibration.py --alpha 0.1

Default --data is training_data_2_sciworld.pkl (this folder). Reads
./trained_models/{best_score_model.pt, bert_cache.pkl} from Stage 3.


================================================================================
5. STAGE 5 — CONFORMAL BFS SEARCH  (bfs_conformal_211.py)
================================================================================

Plays the 211-task MPO test set (mpo_data/test_indices.json), loading the
ALREADY-CALIBRATED pool (no need to rebuild it from data) and computing BERT
embeddings lazily on demand — deliberately RAM-light (~0.5-1 GB/worker
instead of tens of GB) so many workers can run concurrently. Designed to be
sharded: worker --shard-id of --num-shards handles every MPO entry whose
global index is congruent to shard-id mod num-shards.

    for a in 0.1 0.2 0.3; do for s in 0 1; do
      python bfs_conformal_211.py --alpha $a --shard-id $s --num-shards 2 \
        --base_url http://<host>:8001/v1 --model_name Qwen/Qwen3-8B \
        --results results/qwen_211/qwen_a${a}_shard${s}.jsonl &
    done; done

Merge shards afterward by concatenating each alpha's JSONL files (disjoint,
one line per episode).

Options:
    --alpha F              required
    --shard-id N / --num-shards N     (default 0 / 1 = no sharding)
    --method              dual_lp | quantile               (default dual_lp)
    --k N                  top-k calibration neighbours       (default 50)
    --n_components N        SVD components                     (default 10)
    --n_samples N            LLM candidate samples per node     (default 10)
    --temperature F           (default 0.7)
    --max_nodes N              (default 40)
    --max_depth N               (default 50)
    --base_url / --model_name   vLLM endpoint

The BFS algorithm itself (run_bfs_episode + helpers) lives in
bfs_conformal_sciworld_game24_style.py — a FIFO-BFS, set-coverage port of the
Game of 24 method. Coverage is measured only at on-gold-path nodes (the only
place ground truth exists at play time); --oracle_candidates (default on)
unions gold[t] into the LLM candidate pool at those nodes to match how
calibration was built.


================================================================================
6. STAGE 6 — EVALUATION
================================================================================

--- 6a. Offline per-state coverage dump (feeds 6c/6d) ---------------------------

Because online BFS play almost never lands on a gold state, coverage is
measured OFFLINE instead: reproduce the seed-42 held-out val split from the
training data and measure coverage there (same split/method
run_conformal_calibration.py uses). Run once per model:

    python dump_setsize_coverage_sciworld.py \
        --data training_data_2_sciworld.pkl --label Qwen2.5-3B --out setsize_cov_qwen25.csv
    python dump_setsize_coverage_sciworld.py \
        --data training_data_2_sciworld.pkl --label Gemma-4-12B --out setsize_cov_gemma.csv
    python dump_setsize_coverage_sciworld.py \
        --data training_data_merged_sciworld.pkl --label Qwen3-8B --out setsize_cov_qwen3.csv

Options: --data, --model (score-model checkpoint, default trained_models/best_score_model.pt),
--label, --out, --max_test (cap test states, 0=all), --method, --k.

--- 6b. Baseline self-sized-set generator (feeds 6c/6d) -------------------------

    python reflexion_selfset_sciworld.py --data training_data_2_sciworld.pkl \
        --base_url http://<host>:8001/v1 --model_name Qwen/Qwen3-8B \
        --stem qwen3 --k 3

Writes reflexion_selfset_trial{1,2,3}_<stem>.csv directly (no reshape needed,
unlike WebShop/Game24 — this script writes the 3 long-format files itself).

Options: --data, --base_url, --model_name, --stem (output suffix, e.g.
qwen3/qwen25/gemma), --k (max self-sized set, default 3), --max_test,
--temperature, --seed, --out_dir, --workers, --chat (for instruct/chat models).

--- 6c. The prediction-set-size figure -------------------------------------------

    python plot_setsize_distribution_coverage_sciworld.py --coverage

Defaults to all 3 models at once (--csvs setsize_cov_qwen25.csv
setsize_cov_qwen3.csv setsize_cov_gemma.csv, --labels Qwen2.5-3B Qwen3-8B
Gemma-4-12B), one figure per model.

Key options:
    --csvs PATH...       one dump_setsize_coverage_sciworld.py CSV per model
    --labels STR...        matching model labels
    --x                    frac | abs                              (default abs;
                            "frac" bins set size as a FRACTION of admissible
                            actions, since ScienceWorld's action space size
                            varies a lot per state — "abs" uses raw counts)
    --bin_edges F...        (default: auto)
    --coverage              overlay the coverage line                (default off)
    --wide                 two-column-width figure
    --out_prefix            (default setsize_distribution_coverage_sciworld_)

--- 6d. Empirical coverage table --------------------------------------------------

    python table_coverage_vs_setsize_sciworld.py

Options: --csvs / --labels (same defaults as 6c), --bin_edges (default 0 2 4
16), --out_txt / --out_csv (default coverage_vs_setsize_sciworld.txt/.csv).
Rows = method (alpha=0.1/0.2/0.3, ReAct/Reflexion T1, Reflexion T2/T3),
columns = absolute set-size bins + OVERALL + avg size, reading the same
setsize_cov_<model>.csv (6a) and reflexion_selfset_trial{1,2,3}_<stem>.csv
(6b) files as 6c.

--- 6e. LLM-call accounting -------------------------------------------------------

    python count_llm_calls_winning_sciworld.py

Reads a MODELS list hardcoded near the top of the file — per model, the
ReAct/ReflAct/Reflexion JSONL result paths and a glob for the BFS-conformal
sharded JSONLs (e.g. conformal_prediction_gemma/results/gemma_211/gemma_a*_shard*.jsonl).
Edit that list to point at your own results directory layout before running.


================================================================================
7. END-TO-END SUMMARY
================================================================================

    1. python data_generation_sciworld.py --out training_data_sciworld.pkl
    2. python add_optimal_and_bins_sciworld.py --in training_data_sciworld.pkl --out training_data_2_sciworld.pkl
    3. python train_score.py
    4. python run_conformal_calibration.py --alpha {0.1,0.2,0.3}
    5. python bfs_conformal_211.py --alpha {0.1,0.2,0.3} --model_name <model> --results results/<model>_211/<model>_a<alpha>.jsonl
    6. python dump_setsize_coverage_sciworld.py --data training_data_2_sciworld.pkl --label <Model> --out setsize_cov_<model>.csv
       python reflexion_selfset_sciworld.py --data training_data_2_sciworld.pkl --model_name <model> --stem <model>
    7. python plot_setsize_distribution_coverage_sciworld.py --coverage
    8. python table_coverage_vs_setsize_sciworld.py
    9. python count_llm_calls_winning_sciworld.py
